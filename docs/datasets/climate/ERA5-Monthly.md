# ERA5-Monthly

Monthly weather and land-surface state for every cell of the Major TOM grid, 1940–2025: 201 ERA5 variables (temperature, humidity, wind, pressure, precipitation, radiation, clouds, soil, snow, waves and more), with 1991–2020 climate normals. Part of [Major TOM Climate](https://source.coop/major-tom/climate).

## Variables

Every single-level variable ERA5 offers as a monthly mean, except exact duplicates and precipitation type (see Notes); the selection is documented in [ERA5_VARIABLES.md](https://github.com/ESA-PhiLab/Major-TOM/blob/main/docs/ERA5_VARIABLES.md). Columns are `era5_` and ERA5's short name; units are as the Climate Data Store gives monthly means: **accumulated variables (precipitation, evaporation, runoff, radiation and other fluxes) are per day**, the mean daily total of the month. `era5_valid` is the share of the cell covered by source pixels with data.

## Files

| Path | Contents |
|---|---|
| `cells.parquet` | `grid_cell`, `grid_row_u`, `grid_col_r` |
| `series/year=YYYY/MM.parquet` | one row per cell, along the Hilbert curve: `grid_cell`, `grid_row_u`, `grid_col_r`, `year`, `month`, the columns above |
| `climatology/band=NN.parquet` | one row per cell and calendar month, 1991–2020: `grid_cell`, `grid_row_u`, `grid_col_r`, `month`, `<column>_mean`, `<column>_std`, `n_years` |
| `overviews/year=YYYY/MM.parquet` | one row per block of 4 × 4 cells, for maps of the whole globe: `block_row` = (`grid_row_u` + 1002) // 4, `block_col` = (`grid_col_r` + 2004) // 4, `n_cells`, and the means of `era5_t2m`, `era5_d2m`, `era5_tp`, `era5_u10`, `era5_v10`, `era5_msl`, `era5_tcc`, `era5_ssrd` |

There is no `by_cell/` copy for ERA5-Monthly (it would add about 1.8 TB to its 2.5 TB); read a place over time from `series/`, one file per month, or select the columns you need.

```python
import fsspec
import pandas as pd

https = fsspec.filesystem("https")      # reads only the parts of a file a query needs
url = "https://data.source.coop/major-tom/climate/ERA5-Monthly"
july = pd.read_parquet(f"{url}/series/year=2024/07.parquet", filesystem=https, columns=["grid_cell", "era5_t2m", "era5_tp"])
normals = pd.read_parquet(f"{url}/climatology/band=16.parquet", filesystem=https,
                          columns=["grid_cell", "month", "era5_t2m_mean", "era5_t2m_std"],
                          filters=[("grid_row_u", "=", 624), ("grid_col_r", "=", -29)])   # Loch Lomond, 12 months
```

The band of a cell is (row + 1002) × 20 // 2004, with row the signed number in its name (`624U_29L`: 624, band 16). Filter on `grid_row_u` and `grid_col_r`, the numbers in a cell's name (U and R positive, D and L negative): the row-group statistics then let a reader skip the rest of the file. A filter on `grid_cell` reads the whole file. Select columns: a monthly file holds 201 variables.

## Notes

- **Units of accumulations.** Monthly means of accumulated variables are mean daily totals: `era5_tp` in metres per day (× 1000 × days in the month for a monthly total in mm), `era5_ssrd` in J m⁻² per day.
- **Land-only variables.** Soil water and temperature (`era5_swvl1`–`4`, `era5_stl1`–`4`), snow (`era5_sd`, `era5_rsn`, `era5_asn`, `era5_tsn`, `era5_smlt`, `era5_es`), runoff (`era5_ro`, `era5_sro`, `era5_ssro`), skin reservoir (`era5_src`) and leaf area index (`era5_lai_hv`, `era5_lai_lv`) are means over the land part of each cell: pixels with a land fraction of at least 0.5.
- **Precipitation type left out.** `ptype` is a code (rain, snow, freezing rain, ...); a monthly mean of codes has no meaning, so the column is not published.
- **Ocean-only variables.** Wave and ocean-surface variables have values over the sea only.
- **Climatology period.** 1991–2020, the current WMO normal period.
- **Cell means.** Values are area-weighted means over each cell, without interpolation; see the [top-level README](https://source.coop/major-tom/climate).

## Validation

Every month from 1940-01 to 2025-12 is present; every file has one row per cell (5,113,745); 201 variables and `era5_valid`, no `ptype`; the climatology has one row per cell and calendar month (61,364,940 rows) and 30 years in every cell; overviews hold the eight variables listed above for all 1,032 months. The largest shares of missing values are in the ocean-only variables (waves, ocean surface: up to 86% of cells in a month).
