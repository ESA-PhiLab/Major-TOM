# Major TOM — context

Major TOM (Terrestrial Observation Metaset) is a standard for large EO datasets: a global grid of ~10 km cells plus a
shared metadata schema, so datasets from different sensors join on `grid_cell`. Paper: arXiv 2402.12095.

Published datasets:

- Hugging Face, [Major-TOM](https://huggingface.co/Major-TOM): Core-S2L2A, Core-S2L1C, Core-S1RTC, Core-DEM and the
  embedding sets (Core v1).
- source.coop, [major-tom](https://source.coop/major-tom): `climate` (CPC, IMERG, CAMS, ERA5, ERA5-Land monthly,
  ERA5-Static; unlisted), `core-weather` (weather around every Core acquisition), `core-dem` (Core-DEM as TACO),
  `release-test` (one TACO dataset per `majortom.build` source, three cells).
